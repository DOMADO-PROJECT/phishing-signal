# 평가 결과와 검증 범위

[← 제품 소개](../README.md)

초기 225개 비교, Gold v2 144개 비교, 새 기준 205개 후보 비교, **2026년 9월 20일 출시한 c3_v2 epoch3와 고정 정책**의 평가를 순서대로 정리했습니다.<br>
피싱 신호등의 판정은 안전 보증이 아니며 아래 수치도 실제 사용자의 연락 전체에서 측정한 정확도나 피해 예방 효과를 뜻하지 않습니다.<br>

<br>

## 모델을 고른 비교 기록

### 데이터셋을 다시 만든 배경

개발 과정에서 성능 개선이 정체되자 초기 데이터셋의 구성을 점검했고, 문제를 확인한 뒤 데이터셋을 다시 만들어 모델을 평가했습니다.<br>
2026년 9월 16일 비교 기록에는 바뀐 정답 기준으로 새 문항을 작성하고, 예측 전에 정답을 고정한 과정이 남아 있습니다.<br>

9월 4일 [데이터셋 검토 메모](https://app.notion.com/p/3d131721b5898077a214c5c1b06173cc)에서는 Dataset v2의 일부 문항이 실제 수신 문구보다 사용자의 상황 설명에 가까웠다는 문제를 짚었습니다.<br>
원문을 붙여넣는 제품의 입력 형태와 학습 예시가 어긋나고, 문맥이 부족한 Hold와 상황을 설명하는 Safe의 기준이 충돌한다는 지적입니다.<br>
이 메모는 재설계 제안이며, 제안한 수정이 모두 적용됐다는 실행 기록은 아닙니다.<br>

문항과 정답 기준이 다르면 평가 점수를 하나의 성능 추이로 연결하지 않습니다.<br>
모델 간 차이는 같은 평가 안에서 비교하고, 이전 결과는 당시 조건에서 얻은 기록으로 남깁니다.<br>
데이터셋을 다시 만들었다는 이유로 과거 오류나 기준 미달 결과를 삭제하지 않았습니다.<br>

## 1. 피싱 판정 품질

평가 대상은 **2026년 9월 20일 출시한 C3 v2 epoch3와 고정 정책**입니다.<br>
아래 정답률은 모델과 정책을 거친 최종 판정의 결과입니다.<br>

| 평가 조건 | 기록 |
|---|---|
| 최신 평가 식별 | 2026-09-20 출시 기록의 ‘최신 고정 205’ · 데이터셋 고유 버전·해시는 출시 요약에 없음 |

9월 16일 평가와 최신 평가의 표본 수는 모두 205개지만, 출시 기록에서는 서로 다른 평가셋으로 구분합니다.<br>
두 평가의 작성 방식·라벨 분포·정답 기준이 같은지는 출시 요약만으로 확인할 수 없습니다.<br>

두 행은 같은 배포 모델을 서로 다른 평가셋에서 확인한 결과입니다.<br>

### 81.95% 모델에서 현재 모델로 바뀐 기록

9월 16일 출시 기록에는 81.95%를 기록한 고정 4426 모델과 근거 정책을 기본 서비스에 반영했다고 적혀 있습니다.<br>
실제 배포 파일은 같은 후보의 FP16 저장/FP32 연산 실행물입니다.<br>
평가 당시의 배포 보류 기록과 이후 사용자 승인에 따른 출시 기록을 구분합니다.<br>

9월 20일에는 C3 v2 epoch3와 고정 정책으로 교체했습니다.<br>
출시 기록에는 새 실행물의 식별자, 최신 205개와 이전 205개의 결과, 변환·브라우저 일치 검사와 운영 확인이 남아 있습니다.<br>
다만 확인한 저장소·Notion 문서에는 9월 16일 모델보다 우수해서 C3 v2를 선택했다는 동일 조건의 최종 비교나 구체적인 교체 결정 근거가 없습니다.<br>
데이터셋 재설계와 C3 단독 선택에 관한 앞선 기록만으로 이 교체 이유를 단정하지 않습니다.<br>

따라서 SVG는 각 시점의 모델 비교와 배포 결과를 구역별로 보여줍니다.<br>
81.95%에서 80.49%로 떨어진 성능 추이 또는 향상된 성능 추이로 연결하지 않습니다.<br>
두 수치는 모델·정책·평가셋이 다릅니다.<br>
